Privacy Policy

Last updated 13 November 2026

Overview

QW118 is a desktop content tool for brands and creators. After you authorize a TikTok account, the tool uploads a finished video to that account’s TikTok drafts (inbox). The creator reviews the draft in the TikTok app and publishes it there only if they choose to. QW118 does not post, schedule, or publish videos automatically.

This website is a static product site for QW118. It has no login, no account signup, and no data-collection forms. Reading these pages does not create a QW118 account, and the site does not ask you to submit your name, email, videos, or TikTok credentials. Information described below is used by the desktop tool on the device where you run it. It is not collected by this website.

How the tool may be used is described in the Terms of Service. This policy describes the data that use involves.

Data used by the desktop tool

The QW118 desktop tool uses two kinds of information, and only when you choose to connect TikTok or to upload a video:

  • TikTok OAuth and other authorization data needed to connect the TikTok account you select.
  • The video files you choose to upload, and any caption you choose to send with a video.

You choose the account and the files on the device where QW118 is running. The tool does not ask this website for that information, and this website does not receive it. If you do not authorize TikTok, or you do not choose a video, the tool does not have that account’s authorization or that file to send.

Purpose

QW118 uses TikTok authorization data only to authorize TikTok APIs for the account you connect. It uses the video you choose, and any caption you choose to include, only to create a draft in that authorized account.

That is the whole purpose. The data is not used to publish, schedule, or post a video automatically. It is not used to build a profile about you on this website. It is not used for any purpose other than authorizing TikTok and creating the draft you asked for.

Where data is stored

TikTok authorization tokens and your local choices stay on the device running QW118. “Local choices” means the account you connect and the files you select in the tool on that device. This website does not collect those tokens, videos, or captions, and it does not store them.

Because this site is only static pages, it has no user database and no place where a visit would save your TikTok authorization or your video. Handling of a draft after TikTok has accepted the upload is described in the next section.

Sharing

To create a draft, the desktop tool sends TikTok the video you chose, any caption you chose to include, and the authorization data TikTok requires for that request. The recipient of that transmission is TikTok, so the draft can be created in the authorized account. QW118 does not sell personal data. QW118 does not use TikTok authorization data, videos, or captions for advertising.

After TikTok receives the video and the authorization data needed to create the draft, TikTok’s Privacy Policy applies to TikTok’s handling of that information. QW118 does not control TikTok’s systems, TikTok’s retention of a draft, or how TikTok treats an account. A draft that TikTok has created is in the TikTok account, and the account holder reviews it in the TikTok app.

Access and revocation

You can revoke QW118’s access in your TikTok account settings at any time. Revoking access stops the tool from using that authorization to create new drafts. You do not need this website to revoke access. TikTok’s own settings are where that control lives.

Revoking access does not, by itself, delete a draft that TikTok has already created. Drafts that are already in the TikTok account remain there until the account holder deletes or publishes them in TikTok. This website cannot delete those drafts, because it never receives or stores them.

Children

QW118 is not directed at children. The desktop tool and this website are for brands and creators who are allowed to use TikTok and to authorize third-party apps. This website has no signup and does not ask visitors to provide personal information.

Do not use QW118 to authorize a TikTok account, or to upload a video, if you are not allowed to use TikTok or to connect third-party apps to that account.

Changes to this policy

This Privacy Policy may be updated by posting a new version on this page with a revised date. The “Last updated” date at the top of this page is the date of the current version. The previous version is replaced on this page when a new version is posted. Continued use of the desktop tool after an update is posted is subject to the policy then shown here.
